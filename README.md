# Cocokin

Aplikasi mobile Personal Color Analysis & Rekomendasi Makeup untuk mata kuliah Implementasi dan Pengembangan Perangkat Lunak (IPPL).

## Struktur Kode (`lib/`)
- `lib/main.dart` — Navigasi utama aplikasi
- `lib/halaman/` — Halaman tampilan aplikasi (`beranda_page.dart`, `auth_page.dart`, `kamera_page.dart`, `loading_page.dart`, `hasil_page.dart`, `rekomendasi_page.dart`, `detail_produk_page.dart`)
- `lib/backend/` — Server REST API Dart (`server.dart`) & database JSON (`db.json`)
- `lib/services/` — Service penghubung API (`api_service.dart`)
- `lib/models/` — Model data produk & hasil analisis (`product_model.dart`)
