# Cocokin (Flutter Mobile App)

Aplikasi mobile Personal Color Analysis & Rekomendasi Makeup untuk mata kuliah Implementasi dan Pengembangan Perangkat Lunak (IPPL).

## Struktur Halaman (`lib/`)
- `lib/main.dart` — Navigasi utama aplikasi mobile (AppBar & Bottom Navigation Bar)
- `lib/halaman/beranda_page.dart` — Halaman Beranda, Cara Kerja, dan Tentang
- `lib/halaman/auth_page.dart` — Halaman Masuk & Buat Akun
- `lib/halaman/kamera_page.dart` — Halaman Ambil Foto Wajah dengan Panduan Oval
- `lib/halaman/loading_page.dart` — Halaman Proses Analisis Warna Kulit
- `lib/halaman/hasil_page.dart` — Halaman Hasil Analisis (Skin Tone, Undertone, & Personal Color dengan Gembok Blur Premium)
- `lib/halaman/rekomendasi_page.dart` — Halaman Rekomendasi Produk dengan Filter Kategori & Rentang Harga (Budget)
- `lib/halaman/detail_produk_page.dart` — Halaman Detail Produk, Pilihan Shade, dan Tautan Pembelian E-Commerce (Shopee & Tokopedia)
